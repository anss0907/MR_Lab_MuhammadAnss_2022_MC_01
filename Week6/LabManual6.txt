MCT-454L Mobile Robotics
Lab Manual 6: Reactive Navigation Using Turtlbot3
LiDAR in Gazebo Environment
1. Lab Objective
This lab focuses on using LiDAR data to generate motion commands for reactive navigation.
In this session, you will use the /scan topic to perceive the environment and implement
behaviors such as obstacle detection, avoidance, and wall following.

2. Learning Outcomes
After completing this lab, you will be able to:
•
•
•
•

Interpret LaserScan data in ROS 2
Extract directional distance information (front, left, right)
Compute motion commands based on sensor data
Implement reactive navigation without maps

3. Pre-Lab Setup
Launch simulation
export TURTLEBOT3_MODEL=burger
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py

Verify LiDAR topic
ros2 topic list
ros2 topic echo /scan

Visualize scan (optional)
ros2 run rviz2 rviz2

4. Understanding /scan Topic
This section helps interpret LiDAR data structure.
The /scan topic publishes:
•
•
•

ranges[]: array of distances
angle_min, angle_max: scan range
angle_increment: angular resolution

Each index corresponds to a direction around the robot.

5. Lab Tasks
Task 1: Scan Processing
Objective: Extract directional distances.
•
•

•

Subscribe to /scan
Divide scan into regions:
o Front
o Left
o Right
Compute minimum distance in each region

Task 2: Stop-on-Obstacle
Objective: Implement safety behavior.
•
•

Move forward
Stop when front distance < threshold

Task 3: Obstacle Avoidance
Objective: Generate motion decisions.
•
•

If front is blocked → turn
Turn toward side with larger clearance

Task 4: Wall Following
Objective: Maintain fixed distance from wall.
•
•

Use left or right scan
Apply proportional control

Task 5: Behavior Sequencing
Objective: Combine behaviors.
Sequence example:
•
•
•

Move forward
Avoid obstacle
Follow wall in corridor

6. Implementation Guidelines

•
•

•
•

Publish to /cmd_vel
Suggested speeds:
o Linear: 0.1–0.2 m/s
o Angular: 0.3–0.8 rad/s
Handle invalid values (inf, NaN)
Use averaging or min filtering for stability

11. Conclusion
This lab session provided hands-on experience in implementing reactive navigation using
LiDAR data from the /scantopic. Students processed range measurements to extract
directional information and used it to generate motion commands for obstacle detection and
avoidance.
Through this exercise, students developed an understanding of how raw sensor data can be
converted into meaningful control decisions in real time. The lab also highlighted the
importance of parameter tuning, handling noisy sensor data, and designing stable control
logic.
These concepts form a foundation for more advanced topics such as autonomous navigation,
path planning, and sensor fusion in mobile robotics.
