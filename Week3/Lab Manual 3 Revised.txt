Cheat Sheet

Part 1: Setting Up a ROS 2 Workspace
Step 1: Open a Terminal and Create a New ROS 2 Workspace
Open a terminal (Ctrl + Alt + T) and run the following commands:
# Create a new ROS 2 workspace directory and a 'src' folder inside it
mkdir -p ~/ros2_ws/src
# Navigate to the workspace directory
cd ~/ros2_ws
# Build the workspace
colcon build

Step 2: Source the Workspace
# Source the workspace so that ROS 2 recognizes it
source install/setup.bash

To automatically source the workspace every time a terminal is opened, add the following
line to ~/.bashrc:
# Add workspace sourcing to .bashrc for automatic loading
echo 'source ~/ros2_ws/install/setup.bash' >> ~/.bashrc
# Apply the changes
source ~/.bashrc

Part 2: Using GitHub for Version Control
Step 1: Open a Terminal and Install Git (If Not Installed)
# Install Git if it is not already installed
sudo apt install git

Step 2: Configure Git
# Set your Git username
git config --global user.name "Your Name"
# Set your Git email
git config --global user.email "your_email@example.com"

Step 3: Initialize a Git Repository
# Navigate to the 'src' folder of your ROS 2 workspace
cd ~/ros2_ws/src
# Initialize Git in this directory
git init

1. Go to GitHub
2. Create a new repository.
3. Copy the repository URL.

Part 3: Creating a New ROS 2 Package
Step 1: Open a Terminal and Navigate to ROS 2 Workspace
# Navigate to the 'src' folder of your ROS 2 workspace
cd ~/ros2_ws/src

# Create a new ROS 2 package named 'my_turtle_package' using Python

Step 3: Navigate to the Package Directory
